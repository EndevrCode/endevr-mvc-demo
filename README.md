# Endevr MVC Demo (CRUD + SQL Server + Bootstrap)

A clean ASP.NET Core MVC demo app showing real-world fundamentals:
- SQL Server database design + data persistence
- CRUD screens (Create / Read / Update / Delete)
- Razor Views
- Responsive UI with Bootstrap
- Basic JavaScript for UI interactions
- Form handling + validation

This repo exists as a portfolio project for job applications.

---

## Tech Stack

- ASP.NET Core MVC (C#)
- Razor Views
- SQL Server
- Entity Framework Core
- Bootstrap
- JavaScript
- Visual Studio 2022 / VS Code

---

## Features

- Create, view, edit, and delete records
- Server-side validation (ModelState)
- Bootstrap-based responsive UI
- Basic UI behavior with JavaScript (optional enhancements)
